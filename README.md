## A central repo for me to define my agents.md

some parts are sloppy somewhat intentionally, as the agents context gets larger they get more selective in which tokens affect future ones. as such a larger system prompt with redundancies can help better steer the model in the direction you want.

there are some things in here that are only relevant to projects for this account, and a *lot* of opinionated code styles. but i've found that these restrictions on the ai forces them to write more readable and maintainable code closer to human written code.
